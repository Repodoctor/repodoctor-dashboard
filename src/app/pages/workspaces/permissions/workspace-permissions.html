Repository permissions

Org roles set the default: VIEWER can VIEW, MEMBER can ANALYZE, ADMIN and OWNER have ADMIN. Overrides here change what a member can do on one repository. NONE hides the repository from MEMBER and VIEWER.

  • NONE — hidden from MEMBER and VIEWER
  • VIEW — read findings and repository details
  • ANALYZE — request analysis runs
  • MANAGE — reserved for later repository settings
  • ADMIN — change access grants
